## 这是什么

CMP 40HX 是矿卡：出厂被人为压了算力（寄存器 SS0 锁住），PCIe 链路压到 Gen1，BAR1 也被压成 64 MiB。
2026-10-14 起这个包一共做三件事（前两件默认就装，第三件要你自己选）：

1. **解锁算力**（SS0 = 0x88888888，FP32 从 约 1.9 TFLOPs 回到 约 8.35 TFLOPs）
2. **把 PCIe 拉到 Gen2 x16**（双向量测带宽 约 6 GB/s，Gen1 只有 约 3.4 GB/s）
3. **ReBAR 8 GiB**（BAR1 从 64 MiB 变 8 GiB，显存整块映射；只在开机固件阶段能开 —— 选做，见下面专节）

前两件**每次开机自动保持**（开机时固件写寄存器 + 开机任务重训链路）；第 3 件是把解锁固件换成带 ReBAR 的版本并设为第一启动项，同样每次开机自动生效，你不用天天点。

> **锁态卡（算力被固件拒签）也想只把 Gen2 拉起来**：双击 `一键解锁40HX.bat` 选 **3**（不动 ESP/固件启动项、不解算力）。

## 装之前只有几件事要确认（脚本也会自己体检）

| 项 | 要求 |
|---|---|
| 引导 | **UEFI + GPT**（MBR 盘要先 `mbr2gpt`） |
| Secure Boot | **关** |
| BIOS | 见下面这张 **BIOS 6 项检查** 表（已按紧要程度排序：Secure Boot 关是硬门槛；装完第一次开机必须看到 40HX 跑码界面） |
| BitLocker | 关或已暂停（否则改引导链会索要恢复密钥） |
| NVIDIA 驱动 | 已装（GSP 固件要开着；没开脚本会帮你写开关，然后必须**完全关机**才生效） |
| 杀软 | 火绒/360 加信任区 + 关"启动项保护"（见 `文档\使用说明-详细.md` 第 1.1 节） |

**BIOS 里要检查的 6 项（脚本替你做不了，已按紧要程度排序）：**

| 紧要程度 | 改什么（常见叫法） | 设成 | 不改会怎样 |
|---|---|---|---|
| **1 · 必须（硬门槛）** | **Secure Boot**（安全启动） | **Disabled**（老华硕选 `Other OS`） | 解锁固件未签名，开着就不执行 → 算力一直没解锁 |
| **2 · 装后必验证** | 启动顺序：**`40HX Unlock` 排第一** | 装完第一次开机必须看到 40HX 跑码界面 | 脚本写进 NVRAM 的启动顺序 ≠ BIOS 真选了它（客户机实证）—— 没跑码界面 = 固件没被执行，进 BIOS 把它排第一 |
| **3 · 失败排查首查** | **Above 4G Decoding**（4G 以上解码；**铭瑄板上叫 `Above 4GB MMIO BIOS assignment`**） | **建议 Enabled**（主板没这个选项可跳过） | **我们核过的技嘉板该项（`Above 4G Decoding`）IFR 默认就是 `Disabled`，得手动开**；铭瑄板上对应的 `Above 4GB MMIO BIOS assignment` 在 BIOS 里**没有写默认值、我们的工具读不到 ⇒ 现场请直接进 BIOS 读它的当前值**（我们自己的开发机也是手动打开的）。它管的是“平台肯不肯让设备用 4GB 以上的地址”—— 解锁固件要在**主机内存 4GB 以上**放载荷、让显卡 DMA 读回来，读不回来就卡在 `WPR2 NOT UP` / `IMEM[0]=0xffffffff`（固件层），下游表现就是每次开机代码 43。也有单卡主机不开也能解（实测），所以不是“绝对必须”，但**只需进一次 BIOS、不影响系统，就能排除“地址解码”这一层**，排查时排第一。 |
| **4 · 强烈建议** | **CSM**（Launch CSM / CSM Support） | **Disabled** | **和第 3 项是耦合的**：铭瑄 BIOS 里核显 `Aperture Size` 的帮助文本原文写着“选 2048MB 时才**自动**打开 Above 4GB MMIO 分配，且**必须先关掉 CSM Support**” ⇒ 在这类板上 CSM 开着，above-4GB MMIO 就不会被自动打开（那条原文的适用条件是核显 `Aperture Size` 选 2048MB）。另外 CSM 开着容易把系统装成 Legacy/MBR（会被判“固件不是 UEFI 模式”直接中止）。开着 CSM 但系统确实是 UEFI+GPT 的也能解（实测），所以也不叫绝对必须，但**想开第 3 项就得先关它**。 |
| **5 · 建议** | **Fast Boot**（快速启动） | 建议 **Disabled** | 部分固件（Ultra Fast 类）会跳过启动顺序直进 Windows → 解锁固件那次开机没被执行；排查"没出现跑码界面"时必查。（Windows 的"快速启动"是另一回事：它让"关机"变混合关机、GSP 改动不生效，Install 会自动关掉它） |
| **6 · 只影响 Gen2** | 该 x16 槽的 **PCIe 速率** | **Auto**（别锁 Gen1） | 锁 Gen1 就永远上不了 Gen2 x16；设 Gen3/Gen4 也行（自动协商到 Gen2）。只影响 Gen2，不影响算力解锁——纯算力可不管这项 |

位置（各家叫法不同，按关键词找）：华硕 `Advanced → System Agent (SA) Configuration`、技嘉 `Settings → IO Ports`、
微星 `Settings → Advanced → PCI Subsystem Settings`、华擎 `Advanced → Chipset Configuration`；
CSM / Secure Boot / Fast Boot 都在 `Boot` / `Security` 页。逐条报错对照见 `排查指引.md` 第 3 节。

**第 3、4 项到底“必须”吗？（2026-10-15 更新）**

- `Above 4G Decoding`：**不是绝对必须，但建议开**。我们核过的技嘉板该项默认是 **Disabled**（要手动开）；铭瑄平台上对应项的默认值我们的工具读不到（IFR 里没写）⇒ **现场进 BIOS 读它的实值**。它管的是“设备能不能用 4GB 以上地址”，而我们的解锁固件正是在 4GB 以上放载荷。
- `CSM`：**建议关**，且和第 3 项是**耦合**关系（见上表：不关 CSM，above-4GB MMIO 基本开不了）。
- 这两项都设好还是解不开？**下一步是升级主板 BIOS**：2026-10-15 实证 —— 铭瑄 MS-TZZ H610ITX 2.5G 从 `E1.2G(2022-05)` 升到 `E2.4G(2025-07)` 后，同一张卡 `WPR2 UP after 0ms → booter OK (attempt 1) → 解锁成功`；E1.2G 上同一处死活是 `WPR2 NOT up`。⚠ 这是**实测现象**（“升级后同一张卡就通了”），**因果未定案** —— 静态对比只能证明那一版换了哪些组件，证明不了具体是哪一处修好的。升级会顺带把 BIOS 设置重置成默认，所以升级后请把上面 6 项再核一遍。
- 还想更彻底（**可选、尚未定案**）：把 `Control Iommu Pre-boot Behavior` 设成 `Disable IOMMU`。能解锁的技嘉板默认就是关；失败侧铭瑄板默认是开，而解锁固件跑的正是开机（pre-boot）阶段。**纯实验项、可能无效**：客户那台铭瑄板在 E2.4G（仍默认开 IOMMU）下也解锁成功了，说明这项的默认值差异不足以解释全部现象。先设上面第 3、4 项，这一项作为“还不行时再试”。

想先只看不改：双击 `一键解锁40HX.bat` 选 `r`（只体检，什么都不改），或 `Install-40HXUnlock.ps1 -Mode Check`（纯体检，0 项失败即环境 OK）。

上面这 6 项**不用你自己记**：体检会把没到位的项逐条打出来（含各家 BIOS 的菜单路径与关键词），并给你一个出口 ——
菜单里按 `x` = "我先去 BIOS 改这些，改完重跑"，这一步**什么都不改**。
另外，**推荐项只是省事，不是限制**：菜单永远列全部选项，`f` 就是给"我们还没找到解不开的根因"留的强制通道
（会给安装器带 `-ForceLockedBatch`，锁死批次也照装）；但 Secure Boot / BitLocker / MBR 盘 / ESP 挂不上这四项**仍然会拦** ——
它们不是"解锁能力"问题，是装了也不生效（或只留半成品）。

## 哪些能解 / 哪些解不了（2026-10-15 口径更新）

**一句话：不用再拿 VBIOS 版本号去猜了。** 2026-10-14 的交叉换机实证（案例库 C11）推翻了"版本号决定能不能解"这套口径：

同样两张 `90.06.67.00.06` 卡（VBIOS 内容几乎相同）：装在 **精粤 B660I** 上**两张都成功**（算力 + Gen2）；
换到 **铭瑄 H610ITX** 上**两张都失败**（固件起不来、PLM 关窗、每次开机代码 43）。
⇒ **同卡换板、结局翻转；换卡不换板、结局不变**：能不能解多半在**平台（主板 / BIOS 设置项 / BIOS 太老 / 64 位地址解码）**，
不在卡、也不在版本号。所以本包**不再按 VBIOS 版本给结论**，安装器只把版本号念一遍当记录。

那什么情况下真解不了？

| 情况 | 说明 | 怎么办 |
|---|---|---|
| **锁死批次**（POST 寄存器形态 `SS0=0x20000010`） | 算力 + Gen2 都解不了（写入回读硬锁，补写工具放行也写不进） | 安装前只读预检会认出来并问你要不要装；不装就退出（退出码 6，零改动） |
| **平台不配合**（解锁固件在开机阶段起不来） | 症状 = 每次开机代码 43；`40hx_log.txt` 里有 `PLM closed — no booter effect` / `abort:` | 见 `排查指引.md` §5.1c：先 `一键卸载.cmd` + **完全关机**清 43 → **按上面那张 BIOS 6 项表**把设置项设好 + **升级主板 BIOS** → 重装；**别急着判卡死刑**（同卡换板就成功过） |
| 其它没见过的形态 | 装完由那次开机自证 | 把 `一键诊断.cmd` 报告发回来攒样本 |

> **代码 43 ≠ 卡坏了**：解锁固件每次开机都会跑一遍，跑失败会留残留态，驱动就认不了卡。
> 自救两条：① 双击 `一键卸载.cmd` 还原；② 进 BIOS 把 Windows Boot Manager 调回第一启动项（40HX 项不跑就没有 43，Windows 侧 Gen2 工具照常工作）。

1. **把这个文件夹整个拷到那台装 40HX 的电脑上**（U 盘 / 网络都行），文件夹放在哪都行（例如 `D:\40hx-oneclick`）
2. **双击 `一键解锁40HX.bat`**（唯一入口）→ 它会先跑一遍**只读体检**（约 10~15 秒，不碰硬件），然后打印两样东西：
   - `★ 本机推荐：选项 X ——` 理由（判据：设备状态码 / 阻塞项 / Above 4G Decoding 有没有开 / ReBAR 现状；**不按 VBIOS 版本判**）
   - `设置项体检`：哪些 BIOS 项没到位、**去哪儿开**（Secure Boot / Above 4G / PCIe 速率 / CSM / Fast Boot）
   → **直接回车 = 采纳推荐项**（有阻塞项或卡报状态码推 `r`；Above 4G 有证据推 `2`，否则推 `1`），也可以自己挑 `1/2/3/f/r/u/x`
   → 等它自己跑完（首次约 1 分钟；它会自己弹管理员授权）
3. **完全关机再开机**：开始菜单 → 关机（**不是"重启"**），最好拔掉电源线等 10 秒。
   开机时会先闪过一段解锁固件的跑码界面，然后才进 Windows；
   进 Windows 后**双击 `状态自检.bat`** → 看到 `全绿 -- WDDM + PCIe Gen2 + 算力满血` = 成功。

> 残留状态不对就会表现成"开机黑屏一会儿 + 设备管理器里 40HX 提示**代码 43**"。

## 想连 ReBAR（8 GiB 大 BAR）一起开

ReBAR = 让显卡把整块显存一次映射出来（40HX 的 `BAR1` 从 **64 MiB** 变成 **8 GiB**）。跑 AI / 大显存负载更划算，纯玩游戏影响不大。

**只能在开机固件阶段开**（Windows 侧热改实测是死路），所以本包的做法是：把解锁固件换成**带 ReBAR 的版本**，并把它设为第一启动项。

| 步骤 | 怎么做 |
|---|---|
| ① 装 | 双击 **`一键解锁40HX.bat`** → 选 **2**（算力 + Gen2 + ReBAR）。体检会**先读"这块卡在 4G 以上有没有 MMIO 窗口"来判断 Above 4G 有没有开**并给出证据；选 2 时体检没过要输入 `FORCE` 再确认一次；装完驱动就位后还会自动跑一次**只读 BAR 探测**留证据 |
| ② 开机 | **完全关机再开机**。跑码界面里应出现 `[rebar] BAR1 8 GiB active` |
| ③ 复核 | 开机 1~2 分钟后双击 `状态自检.bat`：`[1/5]` 区块里的 `ReBAR` 行显示 **已启用（BAR1 = 8192 MiB）**；或 `nvidia-smi -q` 看 `BAR1 Memory Usage → Total = 8192 MiB` |
| ④ 不想留 | 双击 `一键解锁40HX.bat` 选 `u`（撤销：切回主线 EFI + 删 ReBAR 启动项与文件）；选 `1` 只切回主线 EFI（文件保留） |

**先试一次再决定（可选）**：双击 **`试跑REBAR.cmd`** —— 只对**下一次开机**生效一次（BootNext，不动启动顺序、不动 BIOS），
开机后约 2 分钟自动在本目录生成 `验证报告-latest.txt`（算力 / Gen2 / ReBAR / 代码43 全量核对）；不想留就 `试跑REBAR.cmd undo`。

**必须知道的三条**：

- 主板要 **Above 4G Decoding = Enabled**（这是 **ReBAR 这条路径**的前提；**纯算力解锁不要求**一定有这一项），并且有一块放得下 8 GiB 对齐空间的空闲 64 位 MMIO 窗口。**BIOS 里的 Re-Size Bar Support 开关在这条路径上不是必需的**。
- 不满足时 **EFI 会整体回滚**：系统照常启动，只是 ReBAR 没开（不会黑屏、不会进不去系统），EFI 日志里有原因。
- 目前只在作者本机（B560M + 1 张 40HX + 驱动 616.92）实测过，其它主板/驱动/多卡未验证 —— 所以建议先 `试跑REBAR.cmd` 试一次，或直接走选项 2，随时能退。

## 正常现象（遇到别慌，不是坏了）

- 火绒/360 弹一次 `Exploit/Vulndriver.ad`：**预期**（这几个驱动都是内核级 BYOVD 工具），弹窗里选"信任"即可；被删了开机任务也会自动补回来（信任区怎么加见 `文档\使用说明-详细.md` 第 1.1 节）
- 安装时弹 UAC + 闪一个黑窗口：正常，装完按任意键关闭
- 装完第一次开机比平时慢几秒：先跑解锁固件、再回到 Windows，正常
- **开机后立刻双击 `状态自检.bat` 时 [5/5] 可能显示黄（未实测）**：开机自动重训那一轮要 1 到 3 分钟，脚本读日志时它还没跑完 ——
  等 2 到 3 分钟再跑一次就好。**跑一次「一键修复Gen2」就变绿、重启后又变黄，也是同一件事，不是解锁坏了**（2026-10-08 起脚本会把这种情况说成"未实测"而不是红）。
- **状态正常时不会再有"下一步-重启后看这里.txt"**（2026-10-02 起：只在"真有失败/还没验证过"时才生成，正常了自动清掉）
- **日志不会无限长大**：包内 `logs\` 只保留最近 10 份；机器上 `C:\ProgramData\CMP40HXGen2\windows\logs\postbind.log` 超过 64 KB 自动裁剪，`retrain-last.log` 每次开机覆盖；**只有失败那次**会另存到 `logs\failures\`（留证据用）

## 出问题怎么办（按现象找工具）

- **Gen2 到不了（一键修复Gen2 最后是 [!!]）**：先看它打印的"体检缺口"。缺口不为"无" = 解锁固件的 Gen2 预埋没写进去 →
  ① 重跑 `一键解锁40HX.bat`（选 `1`）→ **完全关机**再开机 → 再跑一次；② 还在 → 双击 `工具-测试与修复\补写Gen2预埋.cmd`（先试跑给你看，再补写，可回滚）。
  **2026-10-05 起**：对"解锁固件的基线门禁把这批卡拦掉了"的机器（ESP 日志里 `[efi-b] abort: baseline mismatch`），
  开机任务会**每次开机自动补写**（新路径带 `-AllowPrime`；实测 XVE_OVR 0→6 后 VSEC/LNKCAP/LNKCAP2/TLS 会自己到位，链路 Gen2 x16），
  寄存器易失所以必须每开机一次；健康机器上**补写分支**不写任何字节（重训本身仍会写根端口的 LNKCTL 目标速率位，这是本包原本就有的行为）。关掉它：**以管理员身份**创建空文件 `C:\ProgramData\CMP40HXGen2\NO_PRIME`（那个目录有 ACL 加固，普通另存会失败）；关掉后那一次开机只做普通重训、不补写预埋（2026-10-10 起已移除"停 ACE"的老路径，新路径失败只记日志）。注意：**完全关机不会持久关掉补写**——寄存器只是复位，若没有 NO_PRIME，下次开机又会补写。

## 想卸载 / 回到没解锁的样子

双击 **一键卸载.cmd**（会弹 UAC 提权，确认后自动卸载）即可；或在管理员 PowerShell 里手动跑：

```
powershell -ExecutionPolicy Bypass -File "Install-40HXUnlock.ps1" -Mode Uninstall -Yes
```

卸载会删掉启动项、开机任务、驱动与服务；**算力在下一次开机就回到未解锁状态**（解锁本来就是每次开机临时写的）。
有几项（GSP 开关、快速启动、目录权限）不会自动还原，卸载结束时会一条条列出来。

## 原理（想搞明白再看）

- **算力**：ESP 上的解锁固件 `\EFI\40HX\40HXUNLK.EFI` 每次开机把 SS0/SS1 写回解锁值，并预埋 4 个 PCIe Gen2 策略寄存器 + 根端口 TLS。
  它来自 **OnlyEFI v0.1.1**（`BardKing-CN/CMP40HX-Unlock-OnlyEFI`，MIT），特点：EFI 阶段**故意不重训链路**，所以不会复位显卡 → 算力与 Gen2 可以并存。
- **PCIe Gen2**：Windows 侧工具 `payload\windows\40hx-retrain-inpout.ps1` 用 `inpoutx64.sys` 直写 GPU BAR0（MMIO）+ `WinRing0x64.sys` 写 PCI 配置空间，只修两个被驱动改写的寄存器再重训根端口 → **全程不停腾讯 ACE-BOOT、不复位显卡**。
- **每次开机的自愈**：开机任务 `CMP40HX Gen2 PostBind`（SYSTEM）跑上面那套；成功率更高，驱动被杀软清了会自动从 ESP 兜底源补回；登录后 60 秒还有一次"补跑"。

- **ReBAR（选做那件）**：换用 `payload\EFI\40HXUNLK-REBAR.EFI` —— 同样是未签名的解锁固件，额外在 EFI 阶段配 XVE + 桥窗口，把 BAR1 放到 8 GiB；由本包自写的 `一键解锁40HX.ps1` 写进 ESP 并设为第一启动项。任一步失败就整体回滚，只在开机时生效。**Windows 侧改不了**（实测驱动会把 XVE 钳回 64 MiB）。

**出处与致谢**：本项目基于开源项目 **CMP40HX-Unlock（https://github.com/PZH1gdmu/CMP40HX-Unlock）** 改进。
